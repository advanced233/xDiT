## 结论及限制

1. 默认 NCCL 已走 SHM，关闭 P2P 后速度基本相同；明确排除了“禁用 P2P 才导致本次低带宽”的解释。
2. GPU 2 在负载下只有 Gen4 x8，单向编码后理论上限约 15.75 GB/s；不能按 Gen4 x16 的约 31.5 GB/s 估算该卡。两卡还跨同 NUMA 内的 PCIe Host Bridge。
3. GPU 0 的主机拷贝可达 20.8–23.6 GB/s；这不意味着两卡 NCCL collective 也能达到这一速度。SHM 中转、链路宽度及共享服务器资源竞争均可能影响结果，本次无法分别量化其贡献，也没有确定 NCCL 未选择 P2P 的底层原因。
